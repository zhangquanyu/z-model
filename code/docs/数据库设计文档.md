# Z-Model 模型管理系统 - 数据库设计文档

## 1. 数据库概述

### 1.1 数据库选型

本系统采用 **MySQL 8.0+** 作为数据库管理系统，选择理由如下：

| 考量因素 | 说明 |
|----------|------|
| 性能 | MySQL 8.0 提供了更好的查询性能和并发处理能力 |
| JSON支持 | 原生支持JSON数据类型，适合存储事件元数据 |
| 事务支持 | 完整的ACID事务支持，保证数据一致性 |
| 社区成熟 | 成熟的社区生态和丰富的工具支持 |
| 兼容性 | 与Spring Boot JPA完美集成 |

### 1.2 数据库命名规范

| 对象类型 | 命名规则 | 示例 |
|----------|----------|------|
| 表名 | 小写英文，下划线分隔 | `requirement`, `model_requirement` |
| 字段名 | 小写英文，下划线分隔 | `model_id`, `data_type` |
| 主键 | `id`，VARCHAR(36)，UUID格式 | - |
| 外键 | `表名_id`格式 | `model_id`, `requirement_id` |
| 索引 | `idx_表名_字段名` | `idx_property_model_id` |
| 唯一键 | `uk_表名_字段名` | `uk_requirement_code` |

### 1.3 字符集与排序规则

- **字符集**: `utf8mb4`（支持完整的Unicode字符，包括emoji）
- **排序规则**: `utf8mb4_unicode_ci`（支持中文排序）

## 2. 数据库表设计

### 2.1 需求表 (requirement)

**用途**: 存储需求信息，是模型创建的前置条件

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| name | VARCHAR(100) | NOT NULL | 需求名称 |
| code | VARCHAR(50) | UNIQUE | 需求编号，系统自动生成 |
| description | TEXT | NULL | 需求描述 |
| status | VARCHAR(20) | DEFAULT 'DRAFT' | 状态：DRAFT(草稿)/PENDING(待审批)/APPROVED(已批准)/REJECTED(已拒绝) |
| priority | VARCHAR(20) | DEFAULT 'MEDIUM' | 优先级：LOW(低)/MEDIUM(中)/HIGH(高)/CRITICAL(紧急) |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `uk_requirement_code` (唯一索引)
- `idx_requirement_status` (普通索引)
- `idx_requirement_priority` (普通索引)

---

### 2.2 模型表 (model)

**用途**: 存储模型信息，模型是属性和方法的容器

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| name | VARCHAR(100) | NOT NULL | 模型名称 |
| code | VARCHAR(50) | UNIQUE | 模型编号，系统自动生成 |
| description | TEXT | NULL | 模型描述 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `uk_model_code` (唯一索引)

---

### 2.3 模型需求关联表 (model_requirement)

**用途**: 建立模型与需求的多对多关联关系

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| model_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 模型ID，关联model(id) |
| requirement_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 需求ID，关联requirement(id) |

**索引**:
- `uk_model_requirement` (唯一索引: model_id + requirement_id)
- `idx_model_requirement_model` (普通索引)
- `idx_model_requirement_requirement` (普通索引)

**外键约束**:
- `model_id` → `model(id)` ON DELETE CASCADE
- `requirement_id` → `requirement(id)` ON DELETE CASCADE

---

### 2.4 属性表 (property)

**用途**: 存储模型的属性定义，属性是方法参数的来源

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| name | VARCHAR(100) | NOT NULL | 属性名称 |
| code | VARCHAR(50) | NULL | 属性编码，系统自动生成 |
| data_type | VARCHAR(20) | NOT NULL | 数据类型 |
| model_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 所属模型ID |
| requirement_id | VARCHAR(36) | NULL, FOREIGN KEY | 关联需求ID |
| required | BOOLEAN | DEFAULT FALSE | 是否必填 |
| default_value | VARCHAR(255) | NULL | 默认值 |
| description | TEXT | NULL | 属性描述 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**数据类型枚举 (data_type)**:

| 值 | 说明 |
|----|------|
| STRING | 字符串 |
| INTEGER | 整数 |
| LONG | 长整数 |
| DOUBLE | 浮点数 |
| BOOLEAN | 布尔值 |
| DATE | 日期 |
| DATETIME | 日期时间 |
| ENUM | 枚举 |
| OBJECT | 对象 |
| ARRAY | 数组 |

**索引**:
- `idx_property_model_id` (普通索引)
- `idx_property_requirement_id` (普通索引)

**外键约束**:
- `model_id` → `model(id)` ON DELETE CASCADE
- `requirement_id` → `requirement(id)` ON DELETE SET NULL

---

### 2.5 方法表 (method)

**用途**: 存储模型的方法定义

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| name | VARCHAR(100) | NOT NULL | 方法名称 |
| code | VARCHAR(50) | NULL | 方法编码，系统自动生成 |
| model_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 所属模型ID |
| requirement_id | VARCHAR(36) | NULL, FOREIGN KEY | 关联需求ID |
| description | TEXT | NULL | 方法描述 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**:
- `idx_method_model_id` (普通索引)
- `idx_method_requirement_id` (普通索引)

**外键约束**:
- `model_id` → `model(id)` ON DELETE CASCADE
- `requirement_id` → `requirement(id)` ON DELETE SET NULL

---

### 2.6 方法参数表 (method_param)

**用途**: 存储方法的参数定义，参数必须从属性中选择

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| method_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 方法ID |
| property_id | VARCHAR(36) | NOT NULL, FOREIGN KEY | 属性ID（参数来源） |
| param_type | VARCHAR(20) | NOT NULL | 参数类型：INPUT(入参)/OUTPUT(出参) |
| sort_order | INT | DEFAULT 0 | 排序序号 |

**索引**:
- `uk_method_property` (唯一索引: method_id + property_id + param_type)
- `idx_method_param_method` (普通索引)
- `idx_method_param_property` (普通索引)

**外键约束**:
- `method_id` → `method(id)` ON DELETE CASCADE
- `property_id` → `property(id)` ON DELETE CASCADE

---

### 2.7 事件流水表 (event)

**用途**: 记录系统中的事件流水，支持统计分析

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 主键ID，UUID格式 |
| name | VARCHAR(100) | NOT NULL | 事件名称 |
| event_type | VARCHAR(50) | NOT NULL | 事件类型 |
| model_id | VARCHAR(36) | NULL, FOREIGN KEY | 关联模型ID |
| amount | DECIMAL(18,2) | DEFAULT 0 | 金额 |
| quantity | INT | DEFAULT 0 | 数量 |
| status | VARCHAR(20) | DEFAULT 'SUCCESS' | 状态：SUCCESS(成功)/FAILED(失败)/PENDING(处理中) |
| event_time | DATETIME | NULL | 事件时间 |
| description | TEXT | NULL | 事件描述 |
| metadata | JSON | NULL | 元数据，JSON格式存储 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**事件类型枚举 (event_type)**:

| 值 | 说明 |
|----|------|
| ORDER_CREATED | 订单创建 |
| ORDER_PAID | 订单支付 |
| ORDER_SHIPPED | 订单发货 |
| ORDER_COMPLETED | 订单完成 |
| PAYMENT_SUCCESS | 支付成功 |
| PAYMENT_FAILED | 支付失败 |
| REFUND_REQUESTED | 退款申请 |
| REFUND_COMPLETED | 退款完成 |
| USER_REGISTERED | 用户注册 |
| USER_LOGIN | 用户登录 |
| USER_LOGOUT | 用户登出 |
| PRODUCT_VIEWED | 商品浏览 |
| PRODUCT_ADDED | 商品加入购物车 |
| INVENTORY_LOW | 库存预警 |
| SYSTEM_ERROR | 系统错误 |
| SYSTEM_WARNING | 系统警告 |

**索引**:
- `idx_event_model_id` (普通索引)
- `idx_event_event_type` (普通索引)
- `idx_event_status` (普通索引)
- `idx_event_event_time` (普通索引)

**外键约束**:
- `model_id` → `model(id)` ON DELETE SET NULL

## 4. 表关系说明

| 关系 | 主表 | 从表 | 关系类型 | 说明 |
|------|------|------|----------|------|
| 模型-需求 | model | model_requirement | 一对多 | 一个模型关联多个需求 |
| 需求-模型 | requirement | model_requirement | 一对多 | 一个需求可被多个模型引用 |
| 模型-属性 | model | property | 一对多 | 一个模型包含多个属性 |
| 模型-方法 | model | method | 一对多 | 一个模型包含多个方法 |
| 属性-需求 | property | requirement | 多对一 | 属性关联一个需求 |
| 方法-需求 | method | requirement | 多对一 | 方法关联一个需求 |
| 方法-参数 | method | method_param | 一对多 | 一个方法包含多个参数 |
| 参数-属性 | method_param | property | 多对一 | 参数引用一个属性 |
| 事件-模型 | event | model | 多对一 | 事件关联一个模型 |

## 6. 数据库配置

### 6.1 连接池配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/zmodel_db?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: admin
    password: password
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      idle-timeout: 300000
      connection-timeout: 20000
      max-lifetime: 1800000
```

### 6.2 JPA配置

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: validate
    show-sql: false
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.MySQLDialect
```

## 8. 性能优化建议

### 8.1 索引优化

| 表名 | 建议索引 | 用途 |
|------|----------|------|
| requirement | idx_status_priority | 按状态和优先级查询 |
| property | idx_model_data_type | 按模型和数据类型查询 |
| method | idx_model_name | 按模型和名称查询 |
| event | idx_event_time_type | 按时间和类型查询事件 |
| event | idx_model_status | 按模型和状态查询 |

### 8.2 分区建议

对于事件表(event)，建议按时间分区：

```sql
ALTER TABLE event PARTITION BY RANGE (TO_DAYS(event_time)) (
  PARTITION p202401 VALUES LESS THAN (TO_DAYS('2024-02-01')),
  PARTITION p202402 VALUES LESS THAN (TO_DAYS('2024-03-01')),
  PARTITION p202403 VALUES LESS THAN (TO_DAYS('2024-04-01'))
);
```

### 8.3 查询优化

- 使用JOIN代替子查询
- 避免SELECT *，只查询需要的字段
- 对大数据量查询使用LIMIT分页
- 使用EXPLAIN分析慢查询

## 9. 数据安全

### 9.1 访问控制

| 用户角色 | 权限 |
|----------|------|
| admin | 所有操作权限 |
| user | 只读和创建权限 |

### 9.2 加密策略

- 密码字段使用BCrypt加密
- 敏感数据字段考虑应用层加密
- 数据库传输使用SSL/TLS

### 9.3 审计日志

记录数据变更操作：

| 字段 | 说明 |
|------|------|
| operation_type | 操作类型(INSERT/UPDATE/DELETE) |
| table_name | 操作表名 |
| record_id | 记录ID |
| operator | 操作人 |
| operation_time | 操作时间 |
| before_data | 变更前数据(JSON) |
| after_data | 变更后数据(JSON) |
