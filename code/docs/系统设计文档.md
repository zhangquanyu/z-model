# Z-Model 模型管理系统 - 系统设计文档

## 1. 系统概述

### 1.1 系统简介

Z-Model 是一个模型管理系统，用于自主创建和管理业务模型及业务流程。系统核心功能包括：**需求管理**、**模型管理**、**属性管理**、**方法管理**、**事件管理**和**业务流程建模**。模型由三个核心部分组成：**属性（Property）**、**方法（Method）**和**需求（Requirement）**。业务流程基于BPMN 2.0标准，支持可视化流程设计和节点模型绑定。系统遵循以下规则：

- 创建模型前必须先创建需求
- 创建属性及方法时需要关联对应的需求
- 方法的出参与入参需要从属性中选择
- 业务流程的任务节点可绑定业务模型

### 1.2 系统目标

- 提供可视化的模型设计能力
- 实现需求、模型、属性、方法的完整生命周期管理
- 支持方法参数的可视化配置（入参/出参从已有属性选择）
- 提供事件流水记录和查询功能
- 支持模型与需求的关联追溯
- 提供基于BPMN 2.0的可视化业务流程建模能力
- 支持业务流程的版本管理和回滚
- 实现流程节点与业务模型的绑定，支持业务追溯

## 2. 系统架构设计

### 2.1 总体架构

系统采用典型的前后端分离架构，前端通过RESTful API与后端进行通信，BPMN流程编辑器基于bpmn-js实现可视化流程设计。

### 2.2 模块划分

| 模块 | 职责 | 主要类/组件 |
|------|------|-------------|
| 需求管理 | 需求的CRUD、状态管理 | RequirementController/Service/Repository |
| 模型管理 | 模型的CRUD、需求关联 | ModelController/Service/Repository |
| 属性管理 | 属性的CRUD、数据类型配置 | PropertyController/Service/Repository |
| 方法管理 | 方法的CRUD、参数配置 | MethodController/Service/Repository |
| 事件管理 | 事件流水的记录和查询 | EventController/Service/Repository |
| 业务流程 | BPMN流程建模、版本管理、节点绑定 | BpmnProcessController/Service/Repository |

### 2.3 核心业务流程

#### 2.3.1 模型创建流程

```
用户创建需求 → 审核通过 → 创建模型 → 关联需求 → 创建属性(关联需求) → 创建方法(关联需求) → 配置入参/出参(从属性选择)
```

#### 2.3.2 方法参数配置流程

```
选择属性 → 配置为入参或出参 → 保存方法参数关系
```

#### 2.3.3 BPMN业务流程建模流程

```
创建业务流程 → 设置基本信息 → 进入流程设计器
    │
    ▼
使用BPMN编辑器绘制流程图
    ├── 添加开始事件、任务、网关、结束事件
    ├── 连接节点形成流程
    └── 为任务节点绑定业务模型
    │
    ▼
保存流程 → 自动创建版本
    │
    ▼
流程管理 → 版本回滚 / 启用 / 归档
```

### 4.1 实体关系图

```
requirement ◄──────────► model_requirement ◄──────────► model
     │                           │                          │
     │                           │                          │
     └───────────────────────────┼──────────────────────────┘
                                 │
                    ┌────────────┼────────────┐

                property      method      event
                    │            │

    ┌──────────────────────────────────────────────────────────┐
    │                    BPMN业务流程模块                       │
    │                                                          │
    │  bpmn_process ◄──── bpmn_process_version                 │
    │       │                     │                            │
    │       │ process_id          │ version                    │
    │       │ bpmn_xml            │ bpmn_xml                   │
    │       │ status              └────────────────────────────┘
    │       │
    │       ▼
    │  process_node_model ──────► model (业务模型)
    │       │                       │
    │       │ node_id               │ model_id

    │       └───────────────────────┘
    │
    └──────────────────────────────────────────────────────────┘
```

### 4.2 核心实体说明

| 实体 | 说明 | 关键字段 |
|------|------|----------|
| Requirement | 需求实体 | id, name, code, status, priority |
| Model | 模型实体 | id, name, code, description |
| ModelRequirement | 模型需求关联 | model_id, requirement_id |
| Property | 属性实体 | id, name, code, dataType, model_id, requirement_id |
| Method | 方法实体 | id, name, code, model_id, requirement_id |
| MethodParam | 方法参数 | id, method_id, property_id, param_type |
| Event | 事件流水 | id, name, eventType, model_id, amount, status |
| BpmnProcess | BPMN流程定义 | id, name, code, bpmnXml, version, status |
| BpmnProcessVersion | BPMN流程版本 | id, processId, version, bpmnXml, changeNote |
| ProcessNodeModel | 流程节点模型绑定 | id, processId, nodeId, modelId |

## 6. 安全设计

### 6.1 认证机制

- 采用JWT（JSON Web Token）进行无状态认证
- 登录成功后返回Access Token和Refresh Token
- Token有效期：Access Token 2小时，Refresh Token 7天

### 6.2 权限控制

- 基于角色的访问控制（RBAC）
- 支持用户角色：管理员、普通用户
- API接口层面进行权限校验

### 6.3 数据安全

- 密码使用BCrypt加密存储
- API请求参数校验
- SQL注入防护（JPA自动参数化）
- XSS攻击防护（前端转义）

- 使用Redis缓存高频访问数据
