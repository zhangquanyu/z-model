# Z-Model 模型管理系统 - 运维手册

## 1. 系统概述

Z-Model 是一个模型管理系统，用于自主创建和管理业务模型。系统采用前后端分离架构，后端基于 Spring Boot，前端基于 Vue.js。

### 1.1 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        前端层 (Vue3)                           │
│   端口: 5173                                                   │
└────────────────────────────────────────┬────────────────────────┘
                                         │ HTTP/HTTPS
┌────────────────────────────────────────▼────────────────────────┐
│                      后端层 (Spring Boot)                       │
│   端口: 8080                                                   │
└────────────────────────────────────────┬────────────────────────┘
                                         │ JDBC
┌────────────────────────────────────────▼────────────────────────┐
│                      数据库层 (MySQL 8.0)                       │
│   端口: 3306                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue.js | 3.4+ |
| 前端 | TypeScript | 5.4+ |

| 前端 | Vite | 5.2+ |
| 后端 | Spring Boot | 3.2.5 |

## 3. 部署指南

### 3.1 数据库部署

#### 3.1.1 创建数据库

```bash
mysql -u root -p

CREATE DATABASE IF NOT EXISTS zmodel_db 
  DEFAULT CHARACTER SET utf8mb4 
  DEFAULT COLLATE utf8mb4_unicode_ci;

CREATE USER 'admin'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON zmodel_db.* TO 'admin'@'localhost';
FLUSH PRIVILEGES;
```

#### 3.1.2 导入数据

```bash
mysql -u admin -p zmodel_db < code/sql/schema.sql
```

### 3.2 后端部署

#### 3.2.1 构建项目

```bash
cd code/backend
mvn clean package -DskipTests
```

#### 3.2.2 运行项目

**开发模式：**
```bash
mvn spring-boot:run
```

**生产模式：**
```bash
java -jar target/zmodel-backend-1.0.0.jar
```

**指定配置文件：**
```bash
java -jar target/zmodel-backend-1.0.0.jar --spring.profiles.active=prod
```

#### 3.2.3 验证服务

```bash
curl http://localhost:8080/api/health
```

### 3.3 前端部署

#### 3.3.1 安装依赖

```bash
cd code/frontend
npm install
```

#### 3.3.2 运行项目

**开发模式：**
```bash
npm run dev
```

**生产模式：**
```bash
npm run build
```

#### 3.3.3 部署到Nginx

```bash
# 将dist目录复制到nginx静态目录
cp -r dist/* /usr/share/nginx/html/zmodel/

# 配置nginx
cat > /etc/nginx/conf.d/zmodel.conf << EOF
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /usr/share/nginx/html/zmodel;
        index index.html;
        try_files \$uri \$uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
    }
}
EOF

# 重启nginx
systemctl restart nginx
```

## 4. 配置管理

### 4.1 后端配置

配置文件路径：`code/backend/src/main/resources/application.yml`

#### 4.1.1 数据库配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://${DB_HOST:localhost}:${DB_PORT:3306}/${DB_NAME:zmodel_db}?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: ${DB_USERNAME:admin}
    password: ${DB_PASSWORD:password}
    driver-class-name: com.mysql.cj.jdbc.Driver
```

#### 4.1.2 Redis配置

```yaml
spring:
  data:
    redis:
      host: ${REDIS_HOST:localhost}
      port: ${REDIS_PORT:6379}
```

#### 4.1.3 JWT配置

```yaml
jwt:
  secret: ${JWT_SECRET:zmodel-secret-key}
  expire-hours: ${JWT_EXPIRE:2}
```

#### 4.1.4 日志配置

```yaml
logging:
  level:
    root: ${LOG_LEVEL:INFO}
    com.zmodel: DEBUG
  pattern:
    console: "%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"
  file:
    name: logs/zmodel.log
```

### 4.2 前端配置

配置文件路径：`code/frontend/.env`

```bash
VITE_API_BASE_URL=http://localhost:8080
```

## 6. 备份与恢复

### 6.1 数据库备份

#### 6.1.1 手动备份

```bash
mysqldump -u admin -p zmodel_db > backup/zmodel_db_$(date +%Y%m%d_%H%M%S).sql
```

#### 6.1.2 自动备份脚本

```bash
cat > /etc/cron.daily/zmodel_backup << EOF
#!/bin/bash
BACKUP_DIR="/backup/zmodel"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p \$BACKUP_DIR
mysqldump -u admin -ppassword zmodel_db > \$BACKUP_DIR/zmodel_db_\$DATE.sql
find \$BACKUP_DIR -name "*.sql" -mtime +30 -delete
EOF

chmod +x /etc/cron.daily/zmodel_backup
```

### 6.2 数据库恢复

```bash
mysql -u admin -p zmodel_db < backup/zmodel_db_20240101_000000.sql
```

### 6.3 文件备份

```bash
# 备份后端代码
tar -czf backup/zmodel_backend_$(date +%Y%m%d).tar.gz code/backend

# 备份前端代码
tar -czf backup/zmodel_frontend_$(date +%Y%m%d).tar.gz code/frontend
```

## 7. 故障排查

### 7.1 常见问题

#### 7.1.1 数据库连接失败

**现象：**
```
Cannot get connection, pool exhausted
```

**解决方案：**
1. 检查数据库服务是否运行：`systemctl status mysql`
2. 检查数据库连接配置是否正确
3. 增加连接池大小：
```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 30
```

#### 7.1.2 端口被占用

**现象：**
```
Address already in use
```

**解决方案：**
```bash
# 查找占用端口的进程
lsof -i :8080

# 杀死进程
kill -9 <pid>
```

#### 7.1.3 前端页面无法访问

**现象：**
```
ERR_CONNECTION_REFUSED
```

**解决方案：**
1. 检查前端服务是否运行：`npm run dev`
2. 检查端口是否正确：默认5173
3. 检查防火墙规则

#### 7.1.4 API请求失败

**现象：**
```
401 Unauthorized
403 Forbidden
```

**解决方案：**
1. 检查JWT Token是否有效
2. 检查用户权限配置
3. 检查CORS配置

### 7.2 日志分析

#### 7.2.1 查看错误日志

```bash
# 查看最近100行错误日志
tail -n 100 logs/zmodel.log | grep ERROR

# 实时查看日志
tail -f logs/zmodel.log
```

#### 7.2.2 分析慢查询

```sql
-- 开启慢查询日志
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 1;

-- 查看慢查询日志
SELECT * FROM mysql.slow_log;
```

### 7.3 性能问题

#### 7.3.1 高CPU使用率

**排查步骤：**
1. 使用 `top` 查看CPU使用情况
2. 使用 `jstack` 分析线程状态
3. 检查是否有死循环或无限递归

#### 7.3.2 内存溢出

**现象：**
```
OutOfMemoryError: Java heap space
```

**解决方案：**
1. 增加JVM堆内存：
```bash
java -Xms2g -Xmx4g -jar target/zmodel-backend-1.0.0.jar
```
2. 分析内存使用情况：
```bash
jmap -heap <pid>
jmap -dump:format=b,file=heap_dump.hprof <pid>
```

## 8. 安全管理

### 8.1 访问控制

#### 8.1.1 防火墙配置

```bash
# 允许HTTP和HTTPS访问
ufw allow 80/tcp
ufw allow 443/tcp

# 允许数据库访问（仅内网）
ufw allow from 192.168.0.0/24 to any port 3306

# 启用防火墙
ufw enable
```

#### 8.1.2 Nginx安全配置

```nginx
server {
    # 隐藏Nginx版本
    server_tokens off;

    # 限制请求大小
    client_max_body_size 10M;

    # 禁止访问敏感文件
    location ~ /\. {
        deny all;
    }

    # 配置HTTPS
    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
}
```

### 8.2 数据安全

#### 8.2.1 数据库加密

- 密码字段使用BCrypt加密
- 敏感数据传输使用SSL/TLS
- 定期更换数据库密码

#### 8.2.2 日志脱敏

- 禁止在日志中打印密码等敏感信息
- 对日志中的用户ID、手机号等进行脱敏处理
