## 3. 开发环境搭建

### 3.1 安装 Node.js

**第一步：检查是否已安装**
```bash
node -v
npm -v
```

如果显示版本号，说明已安装。推荐 Node.js 版本 >= 20。

**第二步：安装依赖**
```bash
cd code/frontend
npm install
```

> 💡 这会下载 `package.json` 中定义的所有依赖包，保存在 `node_modules` 目录下。

### 3.2 启动开发服务器

```bash
npm run dev
```

启动后会看到类似输出：
```
  VITE v5.2.8  ready in 300 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

在浏览器中打开 `http://localhost:5173/` 即可看到项目。

### 3.3 构建生产版本

```bash
npm run build
```

构建成功后，产物会放在 `dist` 目录下，可以部署到服务器。

## 4. 核心技术学习路线

### 4.1 Vue 3 基础

#### 4.1.1 单文件组件结构

每个 `.vue` 文件包含三个部分：

```vue
<script setup lang="ts">
// 脚本部分：写逻辑代码，如变量、函数
import { ref, reactive } from 'vue'

const message = ref('Hello World')
const user = reactive({ name: '张三', age: 25 })

const handleClick = () => {
  message.value = '你好！'
}
</script>

<template>
  <!-- 模板部分：写HTML结构 -->
  <div class="container">
    <h1>{{ message }}</h1>
    <p>姓名：{{ user.name }}</p>
    <button @click="handleClick">点击我</button>
  </div>
</template>

<style lang="scss" scoped>
/* 样式部分：写CSS样式 */
.container {
  padding: 20px;
  background-color: #f5f7fa;
}
</style>
```

#### 4.1.2 常用组合式API

| API | 作用 | 示例 |
|-----|------|------|
| `ref()` | 创建响应式基本类型 | `const count = ref(0)` |
| `reactive()` | 创建响应式对象 | `const form = reactive({ name: '' })` |
| `computed()` | 计算属性 | 根据其他值计算 |
| `onMounted()` | 组件挂载后执行 | 加载数据 |
| `watch()` | 监听数据变化 | 响应数据变更 |

#### 4.1.3 模板语法

| 语法 | 作用 | 示例 |
|------|------|------|
| `{{ }}` | 插值 | `{{ name }}` |
| `v-bind:` | 绑定属性 | `<input :value="name">` |
| `v-model` | 双向绑定 | `<input v-model="name">` |
| `v-if` | 条件渲染 | `<div v-if="show">显示</div>` |
| `v-for` | 列表渲染 | `<div v-for="item in list">{{ item }}</div>` |
| `@click` | 事件绑定 | `<button @click="handleClick">点击</button>` |

### 4.4 Vue Router

#### 4.4.1 路由配置

在 `router/index.ts` 中定义路由：

```typescript
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/',                    // 访问路径
    name: 'Dashboard',           // 路由名称
    component: () => import('@/views/Dashboard.vue')  // 懒加载组件
  },
  {
    path: '/requirements',
    name: 'RequirementList',
    component: () => import('@/views/RequirementList.vue')
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
```

#### 4.4.2 路由导航

```vue
<script setup lang="ts">
import { useRouter } from 'vue-router'

const router = useRouter()

// 编程式导航
const goToDetail = (id: string) => {
  router.push(`/models/${id}`)
}
</script>

<template>
  <!-- 声明式导航 -->
  <router-link to="/requirements">需求管理</router-link>
  <router-link :to="`/models/${id}`">模型详情</router-link>
  
  <!-- 渲染当前路由组件 -->
  <router-view />
</template>
```

### 4.5 Axios 网络请求

#### 4.5.1 API封装

在 `api/index.ts` 中配置：

```typescript
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',    // 所有请求的基础路径
  timeout: 30000      // 请求超时时间
})

// 响应拦截器：统一处理响应
request.interceptors.response.use(
  (response) => {
    return response.data.data  // 直接返回数据部分
  },
  (error) => {
    // 统一处理错误
    console.error('请求失败:', error)
    return Promise.reject(error)
  }
)

export default request
```

#### 4.5.2 接口定义

在 `api/requirement.ts` 中定义接口：

```typescript
import request from './index'

export const getRequirementList = (params?: { page?: number; size?: number }) => {
  return request.get('/requirements', { params })
}

export const getRequirementById = (id: string) => {
  return request.get(`/requirements/${id}`)
}

export const createRequirement = (data: RequirementCreateRequest) => {
  return request.post('/requirements', data)
}

export const updateRequirement = (id: string, data: RequirementUpdateRequest) => {
  return request.put(`/requirements/${id}`, data)
}

export const deleteRequirement = (id: string) => {
  return request.delete(`/requirements/${id}`)
}
```

### 5.2 添加新页面

**步骤1：创建页面组件**

在 `src/views/` 目录下创建新文件 `MyPage.vue`：

```vue

  // 页面加载时获取数据

})
</script>

<template>
  <div class="my-page">
    <h2>{{ title }}</h2>
    <p>这是一个新页面</p>
  </div>
</template>

<style lang="scss" scoped>
.my-page {
  padding: 20px;
}
</style>
```

**步骤2：配置路由**

在 `src/router/index.ts` 中添加路由：

```typescript
const routes = [

  {
    path: '/mypage',

    component: () => import('@/views/MyPage.vue')
  }

```

**步骤3：添加导航菜单**

在 `src/App.vue` 的 `menuItems` 数组中添加：

```typescript
const menuItems = [

```

### 5.3 添加新的API接口

**步骤1：定义接口类型**

在 `src/api/` 目录下创建 `mypage.ts`：


**步骤2：在页面中使用**


## 9. 常见问题

### 9.1 页面空白或报错

**可能原因：**
- 后端服务未启动
- 网络请求失败
- 代码有语法错误

**解决方法：**
1. 检查浏览器控制台错误信息
2. 确认后端服务运行在 `http://localhost:8080`
3. 确认 API 接口地址正确

### 9.2 npm install 失败

**可能原因：**
- 网络问题
- Node.js 版本过低

**解决方法：**
1. 切换网络或使用代理
2. 更新 Node.js 到最新版本
3. 删除 `node_modules` 和 `package-lock.json` 后重新安装

### 9.3 样式不生效

**可能原因：**
- SCSS 文件语法错误
- 样式作用域问题（`scoped`）

**解决方法：**
1. 检查 SCSS 语法
2. 如果需要全局样式，移除 `scoped` 属性

### 9.4 路由跳转失败

**可能原因：**
- 路由路径配置错误
- 组件文件路径错误

**解决方法：**
1. 检查 `router/index.ts` 配置
2. 检查组件文件是否存在
